# 壁纸与外观

点击工作区右上角的调色盘，或进入 **设置 → 壁纸与外观**。窄屏下，调色盘与网页终端收在 **更多工具（···）** 中；使用默认外观时，也可以在这里切换浅色／深色主题。

1. 上传 JPG、PNG 或 WebP 图片（最大 20 MB）。浏览器会等比缩小图片并移除原图元数据，通过 WebSocket 二进制上传处理后的 PNG，最大 6 MB、400 万像素、单边 2560 像素。
2. 可填写风格偏好，再点击 **让 Codex 智能适配**。后台使用本人 Codex 账号和当前模型分析壁纸，生成配色、深浅模式与构图；这一步消耗模型额度，需要支持图片输入的模型。可以关闭设置，稍后回来查看结果。
3. 调整预设名称、铺满／完整显示、水平和垂直焦点、阅读遮罩。等比适配随浏览器尺寸变化，不拉伸原图。
4. 点击 **全页预览** 查看实际工作区，再 **保存并应用**。预览退出后不会写入配置；保存会同时保留壁纸、配色和构图。

每个账号可分别保存最多 12 套桌面预设、12 套手机预设，点击卡片即可切换，无需再次调用 Codex。桌面只能更改桌面外观，手机只能更改手机外观；另一端的列表可查看，但上传、切换、删除与还原均禁用。设备依据浏览器的移动设备标识判断，单纯缩窄桌面浏览器不会切换为手机配置。浏览器的“桌面版网站”等 UA 覆盖会影响设备判断。

**初始外观** 会移除当前设备的壁纸并恢复蓝白浅色界面，保留已保存的预设。删除正在使用的预设会移除该设备的主题；另一设备不受影响。模型调用失败不会改变已应用的外观，可以重试或放弃草稿。上传和生成中的状态独立于聊天对话，后台任务不显示在对话列表。

## 实现与数据

- 主题只接受结构化颜色和构图参数，不接受模型生成的 CSS、HTML、脚本或外部壁纸 URL。前后端共享校验与语义颜色转换，校正正文、次要文字、强调色和按钮文字的对比度。
- 页面、菜单、弹窗、滚动条、Monaco 编辑器和终端使用同一组颜色变量。旧 CSS 颜色通过兼容变量接入主题；新增样式应使用 `--bg`、`--panel`、`--text`、`--muted`、`--accent` 等语义变量。
- 壁纸存放在 `DATA_DIR/users/<username>/wallpapers/`，计入用户存储用量；预设与各设备当前选择保存在 SQLite。图片接口需要登录并校验所属账号，不提供公共分享链接。保留一个未保存草稿，重新上传会替换先前未保存的图片。
- 配置和预设重启后保留；后台任务状态只在内存中保留 30 分钟，服务重启后需要对保留的草稿重新生成。
- 本功能参考从壁纸生成完整皮肤的交互思路，独立实现；不依赖桌面 Codex 的 Dream Skin 技能安装。

本地验证使用模拟模型覆盖成功与失败、HTTP/WebSocket 上传、设备和账号隔离及预设恢复。真实模型效果取决于用户连接的模型和账号。
